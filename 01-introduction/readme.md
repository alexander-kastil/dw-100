# Introduction to the Copilot Business Value Bootcamp

The Copilot Business Value Bootcamp is built to help partners understand how to sell Microsoft 365 Copilot.
We have the following objectives:

- Understand the Copilot Functional Business Value Approach and Scenario Library
- Practice Scenario and Value Discovery in interactive sessions teaching you how to facilitate the envisioning of high-value scenarios by key processes and functions
- Learn how to use the Microsoft Business Case Builder tool to produce a business case with KPI analysis
- Apply your newly learned skills to group activities, creating your own Microsoft 365 Copilot value summary with ROI analysis
